This process describes test_gateway_event_based.

The process begins when Start by Process.
After this (begin), the process moves to Event Gateway.
At Event Gateway (Process), the process waits for an event.
  - The process continues to Message Event (message_received) if this condition is met.
  Next, Message Event (Lane1) triggers an intermediate event.
  After this (process_message), the process moves to Handle Message.
  Next, Handle Message (Lane1) performs a task.
  After this (complete), the process moves to End.
  - The process continues to Timer Event (timer_expired) if this condition is met.
  Next, Timer Event (Lane2) triggers an intermediate event.
  After this (process_timeout), the process moves to Handle Timeout.
  Next, Handle Timeout (Lane2) performs a task.
  After this (complete), the process moves to End.

The process completes when End is reached.
